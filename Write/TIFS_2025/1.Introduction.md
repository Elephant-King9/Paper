# V1

​	感知加密是一种结合图像初始像素信息进行加密来保护图像视觉内容的有效方法。由于图像的信息具有连续性和高密度的特性，导致图像中会出现大量与主体无关的冗余信息。传统加密会不加区分的对图像的全部信息进行加密，并没有结合图像本身的属性，从而导致了大量冗余计算，与传统加密不同，感知加密根据图像的原始信息区分主体与冗余部分，将加密资源于图像关键主体的加密，可以保证用尽可能少的资源达到最好的加密效果。

​	从密码分析的角度出发，现有很多工作【6,7,8,9,10,11】已经从统计攻击、差异攻击和线性攻击等角度尝试分析感知加密图像的安全性，但是常规的密码分析需要严格的了解加密算法的每个细节，这会设计大量的人力与机器的计算资源，同时感知加密更关注图像本身的信息，而这种方法传统密码分析中很难适用。到目前为止，已经有许多工作针对图像进行感知加密【1,2,3,4,5】，这些方法宣称自己可以通过感知加密的方法来保护普通图像的安全性，但是本文提出的方法挑战了感知加密图像的安全性，图一中的实例展示了我们的恢复结果，恢复图像在视觉上非常接近原始图像。

​	随着深度神经网络的发展与Transformer【12】架构在视觉领域的成熟，使用神经网络来恢复感知加密图像的视觉信息成为了一种新的可用方法。目前已经有许多基于CNN和Transformer的深度神经网络进行图像恢复工作【13,14,15,16,17,18】与超分辨率的工作【19,20,21,22,23,24】，并且在相应的领域取得了极大的进展。但是现有的基于图像恢复和超分辨率的网络仅限于恢复信息破坏程度较低的图像，如高斯噪声，运动模糊，雨雾天气等。不幸的是，对于感知加密这种信息破坏程度较高的图像，现有的恢复网络往往束手无策，详见【图1，画个原图->加密->恢复效果的图，同时对比现有的IR、SR网络的恢复结果】。目前也有工作专门针对信息破坏程度高的感知加密图像进行恢复【25,26】，但是这些网络仅使用CNN来进行图像恢复，没有结合注意力机制进行大尺度图像捕捉的能力，同时这些工作针对的加密图像的尺寸较小，并不符合实际中使用图像的尺寸。在轻量化恢复大尺度感知加密图像的工作目前还鲜有人研究。

​	为了解决上述问题，在本文中，我们提出了一个【模型名称A】，旨在建立一个轻量化的恢复网络，不需要任何有关加密算法的先验知识，用尽可能少的计算资源快速恢复大尺度的加密图像。在【模型名称A】中，我们引入了全新定义的采样模块【上采样模块C】与【下采样模块D】来捕获与恢复大尺度加密图像长距离的关联信息，来避免传统大尺度图像捕获特征带来的巨大参数量与计运算量。此外我们提出了【注意力机制B】，通过空洞注意力窗口与局部注意力窗口进一步以低参数量与运算量来捕获图像全局信息。我们还通过全新的残差链接与损失计算方式来保证在轻量化的基础上提高模型的恢复能力。

​	我们的主要贡献如下

- 我们提出了一个结合CNN和Transformer的端到端神经网络【模型名称A】，不需要任何手工分析与对加密算法的先验知识，就可以破解大尺度感知加密图像中的信息。

- 我们提出了【注意力机制B】【上采样模块C】【下采样模块D】，来降低模型的参数量，实现了使用较少资源就可以部署的轻量化网络。

- 我们通过全新的双线性差值残差链接与损失计算方式进一步提高模型的恢复能力，这种思想是可以在其他的图像恢复网络通用以提升网络性能。

- 我们提出的网络相较于现有的图像恢复网络，在感知加密领域取得了远远优于基线的性能。

# V2

​	感知加密是一种结合图像原始像素信息进行选择性加密的有效方法，其核心目标是在不显著增加计算和存储负担的情况下防止攻击者获取图像的敏感视觉内容。与传统加密方法所追求的彻底隐藏明文信息不同，感知加密充分考虑图像在空间结构上的连续性与信息冗余特性，其加密图像在视觉上仍具一定可感知性。具体而言，感知加密通常通过降低图像的视觉质量或扰乱像素空间分布来实现内容保护。迄今为止，已有多项研究【1,2,3,4,5】提出了多种感知加密算法，声称能够在保障视觉安全的同时实现图像内容的快速传输与处理。这种加密方式在提升处理效率的同时，也为后续的信息恢复或授权访问提供了可能性。由于其在加密与恢复过程中的简洁性与高效性，以及在未经授权的破解方面所面临的高度困难，该方法可以被广泛应用于商业机密传输、军事情报通信，甚至恐怖分子信息交流等敏感场景中。

​	设想你是一名政府情报机构的工作人员，在一次任务中截获了某恐怖组织计划袭击目标建筑的加密图像。为了及时识别爆炸物的位置以阻止潜在灾难，你必须在极短时间内从图像中恢复出有效的视觉信息。你首先考虑采用传统的密码分析方法，目前已有诸多研究工作【6,7,8,9,10,11】尝试从统计分析、差分分析和线性攻击等经典密码分析角度对感知加密图像进行破译。然而，这类方法通常依赖于对加密算法结构和参数的充分了解，且在实施过程中往往需要消耗大量时间、人力和计算资源，显然不适用于当前这一紧急情境。相较之下，本文所提出的方法可在极短时间内破译出感知加密图像的大部分视觉信息。如图1所示，我们展示了一个典型的破译结果，破译后的图像在视觉上高度接近原始图像，使你能够准确锁定爆炸物的位置，从而成功阻止了恐怖袭击，挽救了无辜民众的生命。同时该案例也进一步揭示了当前感知加密方法在面对深度模型攻击时，仍可能面临信息被快速且有效破译的安全风险。

​	不幸的是，现有的图像恢复模型在任务目标上与我们的问题存在本质区别。传统图像恢复任务通常更注重重建图像的细节清晰度，因此在模型设计上往往优先考虑重建质量而非计算效率。在处理大尺度图像时，为了提升恢复精度，这类方法通常需在大分辨率特征图上反复堆叠卷积或注意力模块，从而显著增加参数规模与计算开销。尽管已有部分研究尝试在模型结构上进行压缩与优化【27,28,29,30,31,32,33,34,35】，但优化目标的不同导致无法从根本上解决大尺度图像恢复中的轻量化瓶颈。相较而言，本文更关注更关注在极短时间内提取图像中的主体结构信息，从而实现快速破译，而非追求图像细节的完美重建。例如，在破译恐袭目标位置的图像时，我们所需恢复的核心信息是图像中的主体建筑物，而非图像角落处的广告文字。因此，现有的图像恢复网络难以满足我们对大尺度感知加密图像破译任务的轻量化要求。



​	此外，感知加密图像在空间域中存在大范围扰乱，显著削弱了原始像素之间的空间相关性(见图2)，且随着图像尺度增大，像素间的长距离依赖关系愈发重要，模型必须具备跨区域建模能力才能实现有效破译。相比之下，现有图像恢复方法多面向信息破坏程度较轻的任务（如高斯去噪、去雨等），图像结构保留较完整，适合使用局部注意力机制进行高效重建，因而直接迁移到感知加密任务中难以恢复图像的全局结构与语义信息。此外，已有部分研究尝试针对高破坏度的感知加密图像进行破译【25,26】，验证了深度模型的可行性，但所采用的网络结构仅基于CNN，且其处理图像分辨率相对较小，难以适应真实场景中的高分辨率需求。因此，现有的图像恢复网络难以满足我们在大尺度感知加密图像破译任务中对重建质量的有效性与稳定性的实际需求。



​	为了解决加密图像破译与传统图像恢复在大尺度图像上的需求差距，在本文中，我们提出了一个【模型名称A】，旨在建立一个轻量化的恢复网络，不需要任何有关加密算法的先验知识，用尽可能少的计算资源快速恢复大尺度的加密图像。在【模型名称A】中，我们引入了全新定义的采样模块【上采样模块C】与【下采样模块D】来捕获与恢复大尺度加密图像长距离的关联信息，来避免传统大尺度图像捕获特征带来的巨大参数量与计运算量。此外我们提出了【注意力机制B】，通过空洞注意力窗口与局部注意力窗口进一步以低参数量与运算量来捕获图像全局信息。



我们的主要贡献如下

- 我们提出了一个结合CNN和Transformer的端到端神经网络【模型名称A】，不需要任何手工分析与对加密算法的先验知识，就可以破解大尺度感知加密图像中的信息。
- 为了满足加密图像破译任务对于时间与计算资源的限制，我们提出了【注意力机制B】【上采样模块C】【下采样模块D】，其参数量与计算量相比于同尺度的图像恢复网络大幅下降，实现了使用较少资源就可以部署与训练的轻量化网络。
- 我们提出的网络相较于现有的图像恢复网络，在感知加密领域取得了远远优于基线的性能。
