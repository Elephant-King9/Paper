# 自己写的

在本节中，我们给出了感知加密图像方案的定义、攻击者能力以及攻击者的目标

​	加密方案

​	设$$\mathcal{SC}=(\mathcal{F},\mathcal{E},\mathcal{D})$$为感知加密方案，其中$$\mathcal{K}$$为加密等级，$$\mathcal{E}$$和$$\mathcal{D}$$分别为加密算法和解密算法.对于输入的明文图像$$I_G$$,信息加密方通过加密算法$$\mathcal{E}$$和加密等级$$\mathcal{K}$$:

​												$$I_P=\mathcal{E}(I_G,\mathcal{K})$$

​	来获取初始明文图像$$I_G$$根据加密后的图像$$I_P$$。

​	信息解密方通过解密算法$$\mathcal{D}$$和加密等级$$\mathcal{K}$$，通过

​												$$I_G=\mathcal{D}(I_P,\mathcal{K})$$

​	来根据感知加密图像$$I_P$$获取解密后的初始明文图像$$I_G$$

​	攻击者能力

​	假设攻击者仅拥有加密算法$$E$$，且不知道的任何内部信息，攻击者仅能通过输入的任意一张输入图像$$I_G$$来获取感知加密后的图像$$I_P$$，此外，我们假设攻击者拥有足够的计算资源，能够构建并根据初始图像$$I_G$$和加密图像$$I_P$$进行模型训练的能力与各种图像处理技术。

​	攻击者目标

​	攻击者通过大量的初始图像集$$\{I_{G_1},I_{G_2},...,I_{G_n}\}$$生成与之对应的明文-密码图像对$$\mathcal{D}_t=\{(G_1,P_1),(G_2,P_2),...,(G_n,P_n)\}$$，并试图从从给定的加密图像$$P_i$$中恢复出更多的视觉内容。攻击者可以训练一个模型$$\mathcal{M}$$，通过学习参数$$\theta_{\mathcal{M}}$$来建立明文图像$$G_i$$与密文图像$$P_i$$的端到端映射。密文图像$$P_i$$通过模型$$\mathcal{M}$$，生成尽可能与明文图像$$G_i$$接近的恢复图像$$R_i$$

​											$$minimize(\epsilon)$$

​											$\epsilon=\frac{1}{n} \sum_{i=1}^{n}\left\vert G_{i}-R_{i}\right\vert$

​											$$R_i=M(P_i,\theta)$$

或者使用

​											$$\min \sum_{(I_{G_i},I_{P_i}) \in \mathcal{D}_t} \left\vert I_{G_i}-\mathcal{M}(I_{P_i},\theta_{\mathcal{M}})\right\vert$$

​	攻击感知加密方案$$SC$$的目标描述为：给定由加密算法$$E$$加密的任意加密图像$$P$$，攻击者可以使用训练模型$$M$$生成恢复图像$$R$$，该图像R应尽可能接近明文图像$$G$$。
