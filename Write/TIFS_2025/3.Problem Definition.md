# 自己写的

在本节中，我们给出了感知加密图像方案的定义、攻击者能力以及攻击者的目标

​	加密方案

​	设$$\mathcal{SC}=(\mathcal{F},\mathcal{E},\mathcal{D})$$为感知加密方案，其中$$\mathcal{K}$$为密钥，$$\mathcal{E}$$和$$\mathcal{D}$$分别为加密算法和解密算法.对于输入的明文图像$$I_G$$,信息加密方通过加密算法$$\mathcal{E}$$和加密等级$$\mathcal{K}$$:

​												$$I_P=\mathcal{E}(I_G,\mathcal{K})$$

​	来获取初始明文图像$$I_G$$根据加密后的图像$$I_P$$。

​	信息解密方通过解密算法$$\mathcal{D}$$和密钥$$\mathcal{K}$$，通过

​												$$I_G=\mathcal{D}(I_P,\mathcal{K})$$

​	来根据感知加密图像$$I_P$$获取解密后的初始明文图像$$I_G$$

​	攻击者能力与目标

​	假设攻击者仅拥有加密算法$$E$$，且不知道的任何内部信息，攻击者仅能通过输入的任意一张输入图像$$I_G$$来获取感知加密后的图像$$I_P$$，此外，我们假设攻击者拥有足够的计算资源，能够构建并根据初始图像$$I_G$$和加密图像$$I_P$$进行模型训练的能力与各种图像处理技术。

​	攻击者通过大量的初始图像集$$\{I_{G_1},I_{G_2},...,I_{G_n}\}$$生成与之对应的明文-密码图像对$$\mathcal{D}_t=\{(G_1,P_1),(G_2,P_2),...,(G_n,P_n)\}$$，并试图从从给定的加密图像$$P_i$$中恢复出更多的视觉内容。攻击者可以训练一个模型$$\mathcal{M}$$，通过学习参数$$\theta_{\mathcal{M}}$$来建立明文图像$$G_i$$与密文图像$$P_i$$的端到端映射。密文图像$$P_i$$通过模型$$\mathcal{M}$$，生成尽可能与明文图像$$G_i$$接近的恢复图像$$R_i$$

​											$$minimize(\epsilon)$$

​											$\epsilon=\frac{1}{n} \sum_{i=1}^{n}\left\vert G_{i}-R_{i}\right\vert$

​											$$R_i=M(P_i,\theta)$$

或者使用

​											$$\min \sum_{(I_{G_i},I_{P_i}) \in \mathcal{D}_t} \left\vert I_{G_i}-\mathcal{M}(I_{P_i},\theta_{\mathcal{M}})\right\vert$$

​	攻击感知加密方案$$SC$$的目标描述为：给定由加密算法$$E$$加密的任意加密图像$$P$$，攻击者可以使用训练模型$$M$$生成恢复图像$$R$$，该图像R应尽可能接近明文图像$$G$$。

在本节中，我们给出了感知加密图像方案的定义、攻击者能力以及攻击者的目标

​	加密方案

​	设$$\mathcal{SC}=(\mathcal{K},\mathcal{E},\mathcal{D})$$为感知加密方案，其中$$\mathcal{K}$$表示加密所使用的密钥，$$\mathcal{E}$$和$$\mathcal{D}$$分别为加密算法和解密算法.对于输入的原始明文图像$$I_G$$,信息提供方可通过加密算法$$\mathcal{E}$$和密钥$$\mathcal{K}$$，来生成感知加密图像$$I_P$$,即:

​												$$I_P=\mathcal{E}(I_G,\mathcal{K})$$

​	信息接收方方通过解密算法$$\mathcal{D}$$和相同的密钥$$\mathcal{K}$$，对感知加密图像$$I_P$$进行解密操作，恢复出初始明文图像$$I_G$$,即:

​												$$I_G=\mathcal{D}(I_P,\mathcal{K})$$

​	攻击者能力与目标

​	我们假设攻击者仅掌握感知加密算法$$\mathcal{E}$$，但对其内部结构与实现细节一无所知。攻击者只能通过输入任意一张原始图像$$I_G$$，获得其对应的加密图像$$I_P = \mathcal{E}(I_G)$$。此外，我们进一步假设攻击者具备充足的计算资源，能够利用收集到的图像对$$(I_G, I_P)$$进行模型训练，并具备丰富的图像处理能力，以辅助其攻击行为。

​	攻击者首先构造一个包含大量原始图像的训练集 $\{I_{G_1}, I_{G_2}, \dots, I_{G_Z}\}$，并通过加密算法 $\mathcal{E}$ 获得对应的加密图像集 $\{I_{P_1}, I_{P_2}, \dots, I_{P_Z}\}$，从而形成明密文对集合 $\mathcal{D}t = \{(I{G_1}, I_{P_1}), (I_{G_2}, I_{P_2}), \dots, (I_{G_Z}, I_{P_Z})\}$。随后，攻击者试图从每个加密图像 $I_{P_i}$ 中恢复出尽可能接近原始图像 $I_{G_i}$ 的视觉内容。为此，攻击者训练一个深度模型 $\mathcal{M}$，并通过优化模型参数 $\mathcal{K}’ \in \mathcal{M}$ 来最小化加密图像 $I_{P_i}$ 与原始图像 $I_{G_i}$ 之间的重建误差。该过程可形式化为以下优化目标：



$$\mathcal{K}’ = \arg\min_{\mathcal{K}’ \in \mathcal{M}} \frac{1}{Z} \sum_{i=1}^{Z} \mathcal{L} \left( I_{G_i}, \mathcal{M}(I_{P_i}; \mathcal{K}’) \right)$$



其中，$\mathcal{L}(\cdot)$ 表示用于衡量图像重建误差的损失函数，而 $\mathcal{M}(I_{P_i}; \mathcal{K}’)$ 表示由模型在破解密钥参数 $\mathcal{K}’$ 下对密文图像 $I_{P_i}$ 的重建结果 $I_{R_i}$。通过该过程，攻击者期望获得一个模型，通过使恢复图像 $I_{R_i}$的分布拟合原始图像 $I_{G_i}$的分布的过程，获得可以破解图像加密的密钥$\mathcal{K}’$ 。
