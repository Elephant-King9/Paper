  - 传统方法
    - 先显式构造一个分布函数 （如高斯、拉普拉斯等），并通过最大化似然等方法学习参数。这种方法 可行性好（易于计算、推断、评估），但是 灵活性差（难以拟合复杂数据的真实分布）。
  - “Generative Machines” （如 GAN、VAE）
    - 不需要先给出解析形式的概率分布，而是用神经网络去 隐式学习 数据分布模型。这种方法 灵活性好（能近似任意复杂分布），但在一些情况下 可行性差（如 GAN 中不能直接计算生成样本的概率密度）
