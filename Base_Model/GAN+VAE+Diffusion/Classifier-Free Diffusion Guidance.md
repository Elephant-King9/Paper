**Classifier-Free Diffusion Guidance**

- **背景**

  - 分类器指导扩散模型生成需要额外训练一个判别图片类别的模型，用梯度更新Diffusion生成过程从而引导生成过程
- **现有问题**

  - 分类器引导的扩散模型在基于分类器的指标上表现好，是不是因为它越来越像GAN，而GAN本来就擅长在这类指标上拿高分
- **动机**

  -  无分类器引导
    - 不需要单独训练分类器 可以只用扩散模型本身完成引导。
- **贡献**
- **解决思路**

  - 我们不再单独训练一个分类器，而是同时训练一个无条件的去噪扩散模型$$ p_\theta(z) $$（得分估计器 $$θ(zλ)$$），和一个条件模型 $$p_\theta(z|c)$$ （得分估计器 $$θ(zλ, c)$$）。我们用一个神经网络来同时表示这两个模型。对于无条件模型，只需把类别标识符 c 设为“空标记”（∅）即可：$$θ(zλ) = θ(zλ, c = ∅)$$。我们用一个超参数 puncond 来控制，把 c 随机设为 ∅，这样就能在同一个模型里同时训练条件和无条件模型
  - 采样时，我们用条件和无条件得分的线性组合：

    $$\tilde{\theta}(z_\lambda, c) = (1 + w) \theta(z_\lambda, c) - w \theta(z_\lambda)$$
