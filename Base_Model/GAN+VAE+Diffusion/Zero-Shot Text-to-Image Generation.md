**Zero-Shot Text-to-Image Generation**

- **背景**
  - 文本生成图像任务 **过去主要依赖于**：在固定数据集上寻找 **更好的建模假设**（比如网络结构设计、损失函数等）。
  - 这些假设通常包括：
    - **复杂的模型结构**
    - **额外的辅助损失**
    - **附加监督信息**（如物体部件标签、分割掩膜）
- **现有问题**
- **动机**
  - 本文提出一种 **简单的方法**：
    - 用 **Transformer** 网络
    - **自回归地建模** 文本和图像 token，视它们为 **单一数据序列**
  - 当数据量和模型规模足够大时，我们的方法在 **零样本评估** 下，效果可与之前基于特定领域模型 **媲美**。
  - 当 **算力、模型规模、数据量** 都被合理放大时，**自回归 Transformer** 在多个领域（文本、图像、音频）都取得了 **惊人效果**
- **贡献**
  - **一种 基于自回归 Transformer 的简单文本生成图像方法，特别是在 大规模训练 条件下，扩大模型和数据规模，能 显著提升模型泛化能力，零样本性能上，比过去依赖特定领域知识的方法更强。单个生成模型能学到 更广泛的能力（生成不同风格、多样内容）**
- **解决思路**
  - **两步训练策略**
    - 训练 离散变分自编码器（dVAE），把每张 256×256 RGB 图像压缩成 32×32 网格（即 1024 个图像 token）。每个 token 取值空间大小 8192。相比直接用像素，这样将 Transformer 输入序列长度 缩短 192 倍，而视觉质量 基本不降低（见图 1）。
    - 将 最多 256 个 BPE 编码文本 token 和 1024 个图像 token 拼接，训练 Transformer 自回归建模文本 + 图像 token 的联合分布
