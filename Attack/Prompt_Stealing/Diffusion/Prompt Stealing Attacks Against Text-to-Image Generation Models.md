**Prompt Stealing Attacks Against Text-to-Image Generation Models**

- **背景**
  - 文本生成图像模型彻底改变了艺术设计流程，让任何人只需输入被称为“提示词”（prompt）的文字描述，就能生成高质量的图像。
  - 一个能生成高质量图像的高质量提示词，应包含一个“主题”和多个“修饰词”.“主题”是对图像中所描绘对象或场景的自然语言描述；“修饰词”则是指与图像特定元素或风格相关的关键词或短语

- **现有问题**
  - 制作一个高质量的提示词（包含主题和多个修饰词）既耗时又昂贵。
  - 在本研究之前，并不存在大规模的提示词-图像对数据集
  
- **动机**
  - 本文首次研究了一种新型攻击——提示词窃取攻击（prompt stealing attack），该攻击的目标是通过图像逆推出原始用于生成的提示词。

- **贡献**
  - 第一个大规模研究图像生成模型提示词窃取的工作
  - 创建了数据集Lexica
  - 优于目前三种基线方法

- **解决思路**
  - 一个主题生成器（用于推断图像主题）
  - 一个修饰词检测器（用于识别图像中的修饰信息）
  
- **具体解决方法**

  - 数据集收集
    - Hugging Face开源提示词数据集(只有提示词没有图像，80K)=>随机抽取其中5K个=>使用LexicaAPI查询(返回50条结果，包含图像、提示词、图像排列信息)=>的出250K条提示词与图像=>数据清洗（排出了非SD生成、无法解析的提示词和图像、拼图式图像）=>61467对提示词-图像样本
  
    - 将提示词拆分为主题+修饰词，标准化处理=>77616条提示词修饰语=>CLIP划分为五类：流行趋势（trending）、艺术家（artist）、媒介（medium）、艺术流派（movement）和风格特征（flavor）
  
    - 数据集包含61467条提示词和77616条修饰词
  
  - 数据分析
    - 主题只占不到四分之一，修饰词占四分之三多（平均每条提示词包含11个修饰词）
  
    - 修饰词符合二八定律（**Pareto distribution**）
  
    - 用户较少使用艺术流派（movement）
  
    - 风格特征（flavor）的前三个修饰词都是图像质量增强词，如“highly detailed（高度细节化）”和“8k”
  
    - 平均来看，一条提示词中的修饰词中，有 14.32% 属于艺术家类、6.11% 属于流行趋势类、3.25% 属于媒介类、0.98% 属于流派类、75.33% 属于风格特征类
  
    - 用户更倾向于使用“艺术家类”修饰词来引导生成图像呈现特定的视觉风格
  
    - 艺术家类修饰词在语义空间中聚集得非常紧密，且与其他类别距离较远。而其余四类修饰词之间的语义边界则相对模糊。这再次表明艺术家类修饰词在图像生成中具有重要作用。

- **实验**

  - 知名图库 Lexica 中收集了大规模数据集，Lexica 拥有超过 500 万条 prompt 与其生成的图像
    - https://lexica.art/docs

  - 总共收集了 25 万组提示词与图像对，经过去重和预处理后，最终得到 61,467 对数据，我们将此命名为 Lexica-Dataset

  - 量化指标

    - 语义相似性：窃取的提示词应与目标提示词在语义上高度相似，通常通过嵌入空间中的相似度来衡量。
    - 修饰词相似性：窃取的提示词应尽可能包含目标提示词中的修饰词。
    - 图像 / 像素相似性：将窃取提示词再次输入模型后，攻击者期望生成的图像在外观或像素上与目标图像高度相似。

  - 实验设置

    - 生成模型
      - 官方发布的 Stable Diffusion v1.4 模型版本
        - 50 步采样
        - 生成图像的尺寸为 512×512
      - DALLE 调用要花钱，不作为训练，进作为测试
    - PromptStealer
      - Cpation
        - BLIP
        - GIT
        - MS-COCO 数据集上预训练好的 BLIP 和 GIT 模型，然后按照默认设置，在 Lexica 数据集的“图像-主题”对上进行微调
      - 分类器
        - ML-Decoder
        - Query2Label
        - Lexica 数据集总共有 77,616 个不同的修饰词，每个都可以作为多标签分类的一个“类”
        - 考虑出现超过10次的修饰词，共7672个
        - 如果某个词的预测概率大于 0.6，就认为“图里应该有这个风格”
    -  Lexica 数据集按 8:2 分为训练集与测试集，用于训练和评估 PromptStealer

    - Baseline

      - 直接Image Caption

        - MS-COCO预训练的BLIP（Baseline 1）

        - MS-COCO+Lexica微调BLIP（Baseline 2）

      - PromptStealer

        - 完成提示词（77616）个(Baseline 3)

    - 评估指标

      - 语义相似度
        - 目标 prompt 与被窃 prompt 的文本CLIP嵌入之间的余弦相似度

      - 修饰词相似度
        - 目标 prompt 和被窃 prompt 的修饰词集合之间的 Jaccard 相似度
      - 图像相似度
        - 图像相似度是指目标图像与生成图像的CLIP图像嵌入之间的余弦相似度，
      - 像素相似度
        - MSE
      - 人工评分
        - 对每一张目标图像及其对应的被窃图像，会安排两名标注人员使用一个五级打分系统（Like-scaler）进行标注，评分范围从“完全不相似”到“非常相似”
        - 测试集里随机抽取了 10 张目标图像，并报告它们的**平均人工评分**
