**An image is worth one word: Personalizing text-to-image generation using textual inversion**

- **背景**
- **现有问题**
  - 如何利用这种文本到图像去生成某个**特定的、独一无二的概念**，修改其外观，或把它放进新的角色和场景中，仍然不清晰。
  - 我们的问题是：我们如何用语言驱动的模型，把我们自己的猫变成一幅画，或者根据我们最爱的玩具想象出一种新产品？
  - 将新概念引入大模型通常是很困难的。而在少量样本上进行微调又常常会导致灾难性遗忘（即模型忘记了原来的知识）。一些更稳妥的方法则选择“冻结”原模型，通过额外训练转换模块以适配新概念。然而，这些方法仍容易遗忘原有知识，或在使用新学到的概念时，无法同时访问旧知识。比如你让模型学会了“蓝色小猪佩奇”，它可能因此忘记普通“小猪佩奇”长什么样。
- **动机**
  - 我们提出了一种简单的方法来实现这种创意自由。
  - 我们只需 3 到 5 张用户提供的图像（如某个物体或风格），就能在一个“冻结的”文本到图像模型中，用一个新的“单词”来表示这个概念。
  - 我们发现仅用一个词嵌入就足以表达独特且多样的概念
- **贡献**
  - 我们提出了“个性化文本生成图像”任务，即通过自然语言引导，生成包含用户自定义概念的新图像场景。
  - 我们在生成模型背景下提出了“文本反演（Textual Inversion）”的概念，其目标是：在文本编码器的嵌入空间中寻找新的伪词，以同时表达**高层语义**和**细节视觉特征**。
  - 我们借鉴 GAN 的反演技术，对嵌入空间进行了分析，并指出该空间存在“失真与可编辑性”的权衡关系。我们的方法在这个权衡曲线上找到了一个非常理想的平衡点。
  - 我们将该方法与“使用用户提供的描述生成图像”的方式进行了对比，结果显示，我们生成的嵌入向量具有**更高的图像还原度**，同时也支持**更强的图像编辑能力**。
- **解决思路**
  - 我们不再去改动整个模型，而是在模型现有的“词向量空间”中寻找能表示新概念的“新词”。我们的目标是找到能够表示“新的、具体概念”的嵌入向量。我们用一个“伪词”（pseudo-word）来表示这个新的嵌入向量，记为 S∗。这个伪词可以像普通单词一样被使用，用于构建文本生成提示词。你可以请求生成“在沙滩上的 S∗ 的照片”、“挂在墙上的 S∗ 的油画”，甚至组合两个伪词，“S∗1 的画，风格像 S∗2”。
