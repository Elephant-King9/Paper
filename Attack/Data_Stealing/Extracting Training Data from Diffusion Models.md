**Extracting Training Data from Diffusion Models**

- **背景**

- **现有问题**
  - 扩散模型会记住其训练数据中的某些具体图像，并在生成图像时将它们“复现”出来。
  - 我们的研究结果表明，与早期的生成模型（如GAN）相比，扩散模型在隐私保护方面显著更弱；要缓解这些漏洞，可能需要发展新的隐私保护训练方法。
  - 如果扩散模型确实记住并重现了训练数据，那将违反所有隐私保障，并引发关于模型泛化能力和“数字伪造”【65】的一系列问题。
  
- **动机**
  - 担心隐私泄露
    - 首先是理解隐私风险。扩散模型如果重新生成从互联网上抓取的数据，可能会带来与语言模型类似的隐私与版权风险
  - 更清楚的研究扩散模型到底会记住什么
    - 人们常常质疑大规模生成模型所产生的惊艳结果究竟是全新的创造，还是对训练数据的直接复制与拼接
  
- **贡献**
  - 证明了最先进的扩散模型确实会记住并重新生成特定的训练样本。
  - 我们设计了一种两阶段的数据提取攻击方法，该方法先用标准手段生成图像，然后根据成员推理评分标准标记出那些“疑似记住了训练图”的样本。
  - 为了更好地理解记忆现象的产生原因及机制，我们在 CIFAR10 数据集上训练了数百个扩散模型，分析了模型精度、超参数设置、数据增强及去重等因素对隐私的影响。
  
- **威胁模型**
  - 数据提取：攻击者目标是从训练集中还原出某张图像 x \in D。如果攻击者恢复出的图像 \hat{x} 与原图几乎完全一致（详见第4.1节），则攻击成功。
  -  数据重建：攻击者掌握训练图像 x \in D 的部分信息（如局部区域），试图还原整张图像。这类似于属性推理攻击，即从部分信息推测出完整内容。
  - 成员推理攻击：给定一张图像 x，攻击者试图判断这张图是否在训练集中。
  
- **解决思路**

  - 判断是不是真记住了

    - 一、生成的图像和训练集的图像非常像

      - 基于 **Balle 等人 [5] 提出的欧几里得二范数距离**（Euclidean 2-norm distance）来衡量图像之间的相似度，如果小于一个阈值代表模型记住了
      - > Reconstructing training data with informed adversaries.
        >
        > S&P 2022
    - 二、且训练集中相似图像的数量很稀有
  
    - 为了实现实验，还是用数量没那么稀有的测试，也测了很稀有的
  
    
  
- **具体解决方法**

  - ==**黑盒判断**==

    - **从SD中提取数据**
      - **在 Stable Diffusion 的训练集中，利用 CLIP 模型判断哪些图像是“相似的”或“近似重复的”。**
        - 把所有图像用 CLIP 编码成 512 维向量；
        - 再用“余弦相似度”来找出图像中那些“非常相似”的；
    - **用SD对Prompt生成大量图像**
      - 我们为每个文本提示生成 500 张候选图像，以增加发现模型记忆行为的可能性
    - **判断**
      - 把这 500 张图看作一个图（graph），如果某两张图像足够相似（d 距离小），就在它们之间连一条边。
      - 图中存在一个最大团（clique）大小大于等于 10（即有 ≥10 张几乎一样的图），我们就认为这组图代表了一张被记住的训练图。
      - 寻找“团”比直接找相似图对（x₁ ≈ x₂）更有效，误报更少。为了计算这些图之间的距离 d，我们使用了一种改进的欧几里得 ℓ₂ 距离。我们发现仅用 ℓ₂ 距离会导致很多“假相似”，比如图像背景全是灰色，看起来就会很像。因此，我们将每张图分成 16 个不重叠的 128×128 的块，然后取这两个图中所有对应图块的 ℓ₂ 距离的最大值，作为最终的距离度量。
    - **小模型测试**
      - 使用CIFAR-10训练了一个扩散模型生成测试
      - 定义了一个新的评估指标：当某张生成图像与训练集中某图像的 ℓ₂ 距离比其他图像都低很多时，就认定为“记忆”

  - **==白盒判断==**

    - 如果攻击者能看到模型内部信息，那他们就能比较容易地判断某张图片是不是训练数据，这种“隐私泄露”非常广泛。

    - **成员推理攻击**

      - 给一张图判断是不是在数据集里面

      - **损失阈值攻击**

        - 使用**损失阈值攻击**（Loss Threshold Attack）对样本 x，计算其损失值 $l = \mathcal{L}(x; f)$，如果低于某个设定阈值 \tau，就判断该样本是“训练成员”（member）；否则就是“非成员”（non-member）。

        - > Privacy risk in machine learning: Analyzing the connection to overfitting.

      - **似然比攻击**（LiRA）

        - 就像你拿一张照片问一群人：这张照片你见过吗？你先对“见过的人”和“没见过的人”回答反应建模，然后用这个模型来判断另一个人是不是见过它

        - > Membership inference attacks from first principles.

      - **损失函数**

        - 对于扩散模型，**选在哪个扩散时间步计算损失非常关键**。他们发现，在中间扩散阶段（50~300），模型的区分能力最强，也更容易判断某个样本是否被训练过。

        - | 多次噪声采样平均（Monte Carlo） | 每次加入不同的噪声 ε，多次计算 loss 再平均 | 降低loss的随机性，让攻击更稳               |
          | ------------------------------- | ------------------------------------------ | ------------------------------------------ |
          | 图像增强平均（augmentation）    | 对输入图像及其翻转版本都算 loss 并平均     | 模拟训练时的数据增强，更准确判断“是否见过” |

      - 随着模型质量的提升（FID 下降），隐私泄露也在增加。

    - **属性推理攻击**

      - 他们把图片的一部分遮住，看看模型能不能补全被遮住的部分 —— 如果补得太准，说明模型记住了原图。

      - 假设你把一只狗的耳朵遮掉，如果模型能“补”出一个和原图几乎一样的耳朵，说明它可能记住了那只狗的图像。

      - Re-painting

        - > RePaint: Inpainting using denoising diffusion probabilistic models.

        - 同一张图，用同样的掩码，重复修复 5000 次，每次都稍有不同，看哪些修复结果最像原图。

  - **==防御==**

    - **去重训练数据**
      - 很多容易被提取出来的样本，在训练集中被重复了许多次
    - **差分隐私(DP)训练**
      - DP 就是“给训练过程加噪声”，防止模型过分记住某一条训练样本。
      - 可以使用差分隐私随机梯度下降（DP-SGD）[1]对扩散模型进行训练，在该方法中，模型的梯度会被裁剪并添加噪声，以防止模型泄露任何单一图像的信息。
    - **使用金丝雀进行审计**
      - “金丝雀”就像地雷探测器，放几张“独一无二”的图片进去，看看模型会不会记住它们。如果记住了，就说明模型容易泄密。
      - 你插了100张特殊图片（“金丝雀”）进去，然后测模型是否能识别出它们。如果它只认出了插入过的图，那说明它记住了这些“私密内容”。

- **实验**

  - 数据集
    - 论文中展示的所有图像都属于公众人物（如政治家、音乐人、演员或作家），这些人是主动将自己的图像发布到网上的。
  - 他们选了 35 万张重复度高的训练图，为每张图生成 500 张候选图，共 **1.75 亿图**。
  - 使用 clique 相似度 + ℓ₂ 距离筛选出最像训练图的生成图。
